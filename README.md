# AI Academic Feedback System

An AI-powered academic feedback system designed to help academic staff generate, review, edit, and manage personalized feedback for student assignments.

## Overview

The AI Academic Feedback System provides a centralized platform where academic staff can submit assignment information and student answers and receive AI-generated academic feedback.

The system supports academic staff roles such as:

- Instructor
- Assistant Lecturer
- Lecturer
- Senior Lecturer
- Professor

The system allows academic staff to:

- Create new feedback requests
- Provide assignment questions and specifications
- Add optional marking rubrics
- Upload assignment question documents
- Enter or upload student answers
- Generate AI-powered academic feedback
- Review and edit generated feedback
- View previous feedback records
- Search feedback history
- Manage feedback records

## Main Features

### 1. Academic Staff Registration

Academic staff can register using:

- Full Name
- Email
- Academic Role
- Staff ID
- Contact Number
- Password
- Confirm Password

Supported academic roles:

- Instructor
- Assistant Lecturer
- Lecturer
- Senior Lecturer
- Professor

### 2. Academic Staff Login

Registered academic staff can log into the system using their email and password.

After successful authentication, academic staff are redirected to the academic dashboard.

### 3. Dashboard

The dashboard provides an overview of the academic feedback system and quick access to the main functions.

### 4. Create New Feedback

Academic staff can create a new feedback request by providing:

- Module
- Assignment Name
- Assignment Questions
- Assignment Question Document
- Question Specification
- Marking Rubric
- Student Answer
- Student Answer Document

The question specification and marking rubric are optional because they may already be included in the assignment document or question specification.

### 5. AI-Generated Feedback

The system processes the assignment information and student answer to generate personalized academic feedback.

The generated feedback can help identify:

- Strengths
- Weaknesses
- Missing requirements
- Areas for improvement
- Suggestions for improvement
- Overall academic performance

### 6. Edit & Review Feedback

Academic staff can review AI-generated feedback before finalizing it.

They can:

- Review assignment information
- Review student answers
- Review AI-generated feedback
- Edit generated feedback
- Update feedback records

### 7. Feedback History

Academic staff can view previously generated feedback.

The feedback history supports:

- Searching by module
- Searching by assignment name
- Viewing student answers
- Viewing generated feedback
- Updating feedback
- Deleting feedback records
